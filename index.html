Yes for the web desktop. For .exe apps, you need Windows/Mac. On phone we show a QR code to send the link to your PC.

No — V1 is a web desktop that runs in the browser. It's fast, cheap, and works everywhere. Real cloud Windows is a later, expensive feature.
