# Esktop — Your Desktop, Everywhere

Free web desktop + safe desktop app store.

**Live site:** https://esktop.com

## What is Esktop?

- **Web Desktop:** Try a desktop right in your browser. No install needed.
  Files, Notes, To-Do, Calculator, App Store, Student Desktops.
- **Clean App Store:** 50 verified desktop apps.
  No cracks. No fake download buttons. Every Get button goes to the official publisher site.
- **For Students:** One-click desktops for Law, Business, and IT students.
- **For Teams:** Shared desktop, shared files, admin control.

## Tech

- Static site — 1 file: `index.html`
- No build step, no backend needed for V1
- Hosting: GitHub Pages / Vercel
- Notes save in browser (LocalStorage) in V1

## Pricing (Proposal for launch)

- **Free:** $0 — Web desktop, browse app store
- **Pro:** $4.90 / month — Cloud sync, 10GB storage
- **Team:** $9.90 / user / month — Shared desktop

Launch strategy: Launch Free first. Add Pro after 100 real users.
